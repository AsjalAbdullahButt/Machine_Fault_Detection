# 🤖 Machine_Fault_Detection

## Predictive Fault Detection in Robots Using Deep Learning

An academic machine learning project for predictive maintenance and fault classification using LSTM models, SMOTE-based class balancing, and a robot simulator for live risk scoring.

**Prepared as an academic project in the Department of Computer Science, NUCES.**

- 🎓 Academic focus on predictive maintenance for industrial machines and robots
- 🧠 Deep learning pipeline built around binary and multiclass LSTM models
- ⚖️ SMOTE-based class balancing for imbalanced fault data
- 🛰️ Live robot simulator for risk scoring and warning generation
- 📄 Polished PDF report and CSV summary for submission and review

## 📌 Project Overview

This project predicts machine faults from industrial telemetry data and classifies failure types using deep learning. The workflow follows the project proposal and implements an end-to-end pipeline that includes:

- data loading and preprocessing
- feature scaling and class-imbalance handling with SMOTE
- sequence generation for time-series learning
- binary LSTM classification for fault versus no fault
- multiclass LSTM classification for failure type prediction
- evaluation metrics and plots
- a robot simulator that generates live risk scores
- a final PDF report and CSV summary of results

The goal is to demonstrate how predictive maintenance can reduce unplanned downtime by identifying fault conditions before a failure becomes critical.

## 🚀 How to Run

Open a terminal in the project root and run the commands below.

### 1. Install dependencies

```bash
pip install numpy pandas matplotlib scikit-learn imbalanced-learn tensorflow keras reportlab
```

### 2. Run the full pipeline

```bash
python Code/main.py
```

### 3. Run with fewer epochs for a quick test

```bash
python Code/main.py --epochs 1 --no-sim
```

### 4. Use a custom dataset path

```bash
python Code/main.py --csv Dataset/predictive_maintenance.csv
```

### 5. Change training settings

```bash
python Code/main.py --epochs 30 --timesteps 10 --batch 64 --sim-steps 200
```

## 🧪 What the Program Does

When you run `main.py`, the program:

1. loads the predictive maintenance dataset
2. cleans the input data and encodes machine type and failure labels
3. scales the features
4. balances the training data using SMOTE
5. creates sliding time-series windows for the LSTM models
6. trains a binary LSTM for fault detection
7. trains a multiclass LSTM for failure type classification
8. evaluates both models with accuracy, precision, recall, F1, and ROC-AUC
9. generates plots and summary files
10. builds a PDF report named `Report.pdf`
11. optionally runs the robot simulator to produce live risk logs
